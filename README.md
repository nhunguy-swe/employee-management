## Getting Started

```bash
git clone https://github.com/nhunguy-swe/employee-management.git
cd employee-management
mvn compile
```

Then run the class containing the `main()` method from your IDE, or via:

```bash
mvn exec:java -Dexec.mainClass="<your.package.Main>"
```
